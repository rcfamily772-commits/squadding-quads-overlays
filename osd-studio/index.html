02 / PIXEL LOGO STUDIO

Design your boot logo

Draw directly on the pixel canvas or stamp text. Native 288 × 72 pixels for Betaflight's analogue MAX7456 Font Manager. Green represents transparent pixels.

The PNG is not embedded into the HEX. Import it into Betaflight's Font Manager / Boot Logo on supported analogue hardware, then upload the font. DJI, Walksnail and HDZero use different font/display workflows.

Before flashing

Back up your exact target's official firmware and configuration. Remove propellers, verify board target and firmware version independently, and bench-test arming prevention, receiver, failsafe and all OSD warnings before any flight. HEX checksums verify record integrity only, not executable correctness, firmware signatures or image-level checksums. This app cannot verify source references, target identity or signed images. Do not use patched firmware for flight until validated.

For normal in-flight custom wording, prefer Betaflight's native craft/pilot name or custom-text elements if your build supports them; configure placement in its OSD tab. Arbitrary new graphics or longer firmware strings require a target-specific source build or supported font workflow.
