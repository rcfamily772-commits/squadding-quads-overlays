# SQ LiPo Butler v1.1 — Fleet Edition

[Version 1.1 website](https://rcfamily772-commits.github.io/squadding-quads-overlays/lipo-butler/v1.1/) · [Actual Lua test](https://rcfamily772-commits.github.io/squadding-quads-overlays/lipo-butler/test/) · [Browser manager](https://rcfamily772-commits.github.io/squadding-quads-overlays/lipo-butler/app/) · [Radio ZIP](SQ_LiPo_Butler_v1.1.zip)

- Radio: 24-pack filtered fleet grid, touch or key selection, premium pack details and state confirmation, inventory distribution, optional SFX and save feedback.
- Browser: search/filter/sort, custom names and notes, 200-event local activity history, JSON backup/restore, radio slot import, CSV and print.
- Same SQLP1 radio save format and browser storage key as v1.0. Back up both SD slot files before upgrading. Browser names, notes and activity are not synced to radio.
- Install WIDGETS/SQLiPo/main.lua. Fleet > Prev/Next/Open or tap a card; State > Apply; Setup > Field/+/-/Capture; Summary. SFX off by default. Colour screens 320x240 or larger; physical validation pending.
- Manual states only. No battery health, automatic identification, state-of-charge estimates, charging or arming controls. Confirm actual pack condition. Test bench uses simulated 23.4 V and SD storage.
