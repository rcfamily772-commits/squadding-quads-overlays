Keep your packs organised

Up to 24 numbered packs, individual cell counts and capacities.
Five manually confirmed states and recorded charge/flight events.
Fresh optional voltage telemetry, with manual voltage snapshot per pack.
Two validated SD save slots, with fallback to the previous valid save.

Install

  1. Extract the ZIP and copy WIDGETS/SQLiPo into your SD card's WIDGETS folder. Restart the radio and assign SQLiPo to a colour-screen widget zone.
  2. Set Packs (1–24), Cells and Capacity (initial defaults only) and VoltSrc (default VFAS; optional discovered pack-voltage sensor) in Widget Settings.
  3. Open full screen. Prev/Next selects a numbered pack. State opens a selection screen; Apply confirms the new manual state. Setup edits cells/capacity and lets you explicitly capture a fresh voltage snapshot for the connected pack.
  4. Summary shows state counts and a reminder to inspect flown packs before storage. Save files packs-a.txt and packs-b.txt are in WIDGETS/SQLiPo. Back up both.

Try before installing

The interactive test page runs the actual Lua code on five simulated radio displays, with a simulated SD card and clearly labelled demo voltage. It does not connect to your radio.

Safety and compatibility

Colour-screen EdgeTX, 320 × 240 or larger. Tested in Lua simulation; physical radio validation pending. Charge and flight counts are manually recorded state transitions, not automatic charger measurements. The widget cannot identify which battery is connected; live voltage is explicitly unassigned. It cannot measure state of charge, battery health or individual cell balance, and never controls charging or arming. Verify battery condition and follow your battery manufacturer's instructions. Use one widget instance for inventory edits.

The browser inventory is independent, but can import a copy of the radio's saved slot file. No cloud sync. A failed SD save is flagged; the previous valid slot is retained where possible.
