Install or upgrade

  1. Back up your SD card, especially WIDGETS/SQLiPo/packs-a.txt and packs-b.txt. Extract the ZIP and replace the existing WIDGETS/SQLiPo/main.lua. Restart the radio.
  2. Open SQLiPo full screen. Fleet shows the inventory; Prev/Next and Open or tap a pack. Filter cycles all states. State opens a confirmation screen, Setup edits profile or captures voltage, Summary shows the inventory review.
  3. Widget settings retain Packs, Cells, Capacity and VoltSrc. Optional SFX is off by default. Existing v1.0 save slots remain compatible.

Try it before installing

Interactive test page runs actual Lua in the shared emulator with synthetic voltage and simulated storage. Physical hardware testing remains open.

Manual status labels and event counts, not measured battery health or state of charge. No charging or arming controls. Live voltage is unassigned until you explicitly capture it. Verify actual pack condition and follow manufacturer guidance. Browser metadata and activity are local and independent of radio data. Radio save import replaces browser inventory after confirmation.
