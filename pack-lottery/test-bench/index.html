What this bench simulates

Load a single main.lua from an unzipped widget folder. Your file runs locally in this browser. Changing the screen or view starts a fresh instance.

Supports create and refresh, default widget options, getTime, tap and navigation events, and common LCD shapes and text. Screen sizes are pixel presets. Colours, fonts, text metrics, event values and timing are approximations. Widgets requiring telemetry, model data, arbitrary SD files, audio or other firmware APIs need a radio simulator or a radio.
