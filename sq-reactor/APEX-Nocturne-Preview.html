ON THE RADIO

Fit the widget.

The main target is a 480 × 272 landscape display. Larger zones reflow; small or portrait zones use a compact layout.

  1. Copy the widget.Extract the ZIP to the SD card root, giving /WIDGETS/SQDash/main.lua. Restart EdgeTX and add SQDash to a large widget zone.
  2. Choose Nocturne.Set Theme = 7. Theme 6 selects the ice-blue APEX edition. Choose Layout 1–4 and your speed and altitude units.
  3. Match your arm source.Set ArmSrc to the dedicated arm AUX channel or matching two-position switch. Set ArmHigh to match its direction. Verify both positions with propellers removed.
  4. Verify telemetry.Discover sensors and compare values with your flight controller. Set Cells to your verified pack count. Enable LogSD only if you want per-model SD history.
Telemetry, logging & validation notes

Colour EdgeTX 2.11+ target (eight widget settings); older radios can use the archived v1.3. Speed and altitude require compatible sensors and units. Statistics are sampled, not blackbox maxima; missing and stale readings are excluded, data gaps can cause missed extrema. Arm status follows the configured radio source, not confirmed FC arming. Reports stay in memory until re-arm, settings changes or widget reload. Session records survive re-arm but not settings changes or reload; saved aircraft records survive radio restart. Power is estimated from sampled voltage × current; the speed average is a sample mean, not a distance/time calculation. The trace contains up to 36 approximately one-second samples. No flight controls, model writes or sounds. Opt-in SD logging appends one CSV row per observed disarm to /LOGS/SQD_<model filename>.csv. It loads incrementally while disarmed; the latest eight rows and aircraft records appear in Logbook. Archive the CSV at the 256 KiB limit. Missing or partial samples are marked; SD failure or re-arming before a pending save may prevent logging. Model filename reuse shares history. Battery drop is measured from the first armed voltage, not a direct internal-resistance measurement. This is an experimental field preview. Physical-radio validation is pending; test disarmed and remove if radio performance suffers.

The browser executes the downloadable widget’s Lua drawing code with synthetic state. Browser fonts and LCD rendering are approximations; it is not an EdgeTX firmware simulator. The Nocturne figures use the same triangle outlines here and on the radio.
