# SQ Tools — Black Label Collection

[Open the central tools hub](https://rcfamily772-commits.github.io/squadding-quads-overlays/tools/)

- **[SQ Pilot Dash · APEX Nocturne](../sq-reactor/)** — Preview four EdgeTX telemetry layouts and download the v1.8.1 radio widget. Select Theme 7 for Nocturne.
- **Pack Lottery** — Draw a real-world FPV challenge from six decks. Collect rare cards, earn achievements and build your Pilot Passport.
- **Wallpaper Shuffle** — Give your radio a fresh look every time it starts. Browse the SQ wallpaper library, shuffle manually or hide the controls for a clean view.
- **RF Doctor** — See live radio-link telemetry, capture session statistics and compare exported CSV logs from two test flights in the browser.
- **LiPo Butler** — Organise up to 24 battery profiles, manually confirm pack states, log charge and flight events and keep track of voltage snapshots.
- **OSD Studio** — Design an analogue boot logo, inspect Intel HEX files and experiment with a narrowly supported post-flight statistics heading replacement.
- **EdgeTX Test Bench** — Try supported SQ Lua widgets on your phone or PC, or load your own Lua file. Switch display sizes and simulate touch or navigation keys.
- **OBS Glass Overlays** — A frosted-glass overlay preview for subscribers, live chat and supporter acknowledgements. Explore demo controls before setting up live integrations.

The hub links to existing apps and downloads; no application code is changed. Artwork previews are illustrative. See individual project pages for safety and compatibility limitations.
