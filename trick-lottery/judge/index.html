How to use

  1. Draw a supported card. Select Score It in the interactive widget.
  2. Choose the actual ARM output channel CH5–16 and high/low polarity. Confirm correct behaviour and aircraft agreement on the bench with props removed.
  3. Check required sensors. Start while disarmed. Record automatically on arm, without touching the radio in flight.
  4. Land, disarm, then reopen the interactive widget to view results.
