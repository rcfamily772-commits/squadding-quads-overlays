Upgrade safely

Back up SQLotto before replacing main.lua. Keep album-a.txt and album-b.txt; v2 reads old radio collection and saves to trick-a.txt / trick-b.txt. Browser retains existing storage keys on this origin. Export a collection backup first.

Copy WIDGETS/SQLotto to SD card and restart. Colour EdgeTX screens 320×240+. Mode and Theme use numeric settings (1–5, 1–6). Use on ground only. Simulator-only cards are excluded from other modes. Never attempt challenges beyond your skill or conditions.

Radio field preview: hardware compatibility and SD persistence need physical testing. Browser and radio collections are separate. Daily/weekly matching assumes the same date; radio uses local calendar, web UTC.
