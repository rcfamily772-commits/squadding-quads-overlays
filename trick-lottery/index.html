EdgeTX: upgrade safely

Back up SQLotto before replacing main.lua. Keep album-a.txt, album-b.txt, trick-a.txt and trick-b.txt. Delete main.luac if present; v2 reads old radio collection and saves to trick-a.txt / trick-b.txt. v2.5 migrates older 60/100-card saves to 125 cards. Older radio versions cannot read newly written SQ25 saves; retain a backup. Browser retains existing storage keys on this origin. Export a collection backup first.

Replace WIDGETS/SQLotto/main.lua on the SD card, preserving all other files, and restart. The optional standalone tool is included for users who already use it; exit it before flying. Colour EdgeTX screens 320×240+. Mode and Theme use numeric settings (1–6, 1–6). Use on ground only. Simulator-only cards are excluded from other modes. Never attempt challenges beyond your skill or conditions.

Radio field preview: hardware compatibility and SD persistence need physical testing. Browser and radio collections are separate. Daily/weekly matching assumes the same date; radio uses local calendar, web UTC.
