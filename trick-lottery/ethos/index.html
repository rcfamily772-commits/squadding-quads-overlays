Install on ETHOS

  1. Extract the ZIP.
  2. Copy the SQTrick folder from scripts into the radio scripts folder (SCRIPTS:/SQTrick/main.lua).
  3. Restart the radio and add SQ Trick Lottery to a full-screen widget layout.
  4. Draw on the ground. Field is default; tap Field to toggle Simulator. Retry keeps the card; Landed records completion.

Preview limitations

Hardware and actual ETHOS simulator testing are pending. Target: colour ETHOS radios such as the X18/X18RS and X20 families. Radio counters are session-only; web records persist locally. No quad decks, collection import, or telemetry/flight-control changes. Use only before take-off and after landing. Never fly simulator-only cards in the real world.
