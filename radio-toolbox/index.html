01 / CONNECT

My radio

Disconnect aircraft batteries. Connect your radio with a USB data cable, select USB Storage (SD), then choose the SD card root. Do not select the internal settings drive.

If the browser cannot see the radio drive, export a ZIP below and use your device's file manager to extract it to the SD card.

02 / ARTWORK STUDIO

Make it yours.

Confirm your active theme folder. Assign model images manually on the radio. Colour radios only for splash and wallpaper.

03 / SOUND STUDIO

Give it a voice.

Converts to mono 32 kHz 16-bit PCM WAV. Assign custom tracks via Play track on the radio. Startup sound must be enabled. No safety alert overrides.

04 / WIDGET LIBRARY

Build your dashboard.

Download and extract a trusted widget package, then select its WIDGETS folder or the package root.

Trick Lottery ↗Wallpaper Shuffle ↗RF Doctor ↗LiPo Butler ↗

Imports WIDGETS files only. Install other package assets separately and add widgets to your screen manually.

05 / RADIO DOCTOR

Check your storage.

Scan common EdgeTX SD folders and back up visible RADIO and MODELS files without modifying them.

Folder check only. Internal radio storage or separate volumes are not included. EdgeTX manual ↗

06 / REVIEW & INSTALL

Installation queue 0 files

Direct apply backs up originals to a ZIP before overwriting and verifies file checksums after writing. Failed writes can leave partial changes. Restore originals from backup and remove new files if necessary.

Eject safely and restart. Check radio operation before flight. No RF, calibration, mixers, failsafe, firmware or model settings writes.
