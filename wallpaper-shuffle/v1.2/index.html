Install

  1. If not already installed, download the v1.1 full pack and choose your radio resolution.
  2. Back up /WIDGETS/SQWall. Extract the v1.2 upgrade, replace main.lua only, remove a stale main.luac if present and keep last.txt and art.
  3. Restart, open the widget full screen and select Prev, Lucky, Next or Clean. Tap or press Enter to leave clean preview. The home tile remains wallpaper-only.

Intro and Motion default on; SFX off. Catalogue count includes fallback entries, so missing images are skipped. The upgrade does not include new wallpaper images or modify the boot splash. Colour radios only; hardware testing pending. v1.1 artwork details.
