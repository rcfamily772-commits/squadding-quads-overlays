Build your radio upgrade

Choose the FPV Dads & Sons Full Art ZIP or the SQWall v1.3 upgrade ZIP supplied with the artwork. The image files are not hosted here. This builder reads your local ZIP, selects the exact size and combines it with the published v1.3 Lua. Files stay in your browser.

Select your artwork ZIP to start.

No automatic boot splash replacement. Optional Pocket/Taranis monochrome art is for Companion splash customisation, not the colour widget.

Installation

  1. Back up the SD card. Install the v1.1 full artwork kit first if necessary.
  2. Build a ZIP above, or use the supplied complete v1.3 upgrade ZIP and choose one Colour_ resolution folder.
  3. Merge IMAGES and WIDGETS with the SD root. Replace SQWall/main.lua, remove any stale main.luac, and keep existing artwork and last.txt.
  4. Restart. Open SQWall full screen to browse FPV Dads & Sons. Use Clean to hide controls.
