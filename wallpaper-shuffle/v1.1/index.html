Install or upgrade

  1. Extract the v1.1 ZIP and select one matching folder under Colour/.
  2. Back up your SD card, including any existing IMAGES/splash.png. Merge the selected WIDGETS and IMAGES folders into the storage root.
  3. Replace the old main.lua; remove any stale main.luac. Keep last.txt. Eject safely and restart.
  4. Assign SQWall to a large colour-screen widget zone. Ensure the SD card is writable and the clock is set.
  5. Open the widget full screen and tap I'm Feeling Lucky or press Enter. Disable Intro in widget settings if preferred.

Native boot splash support depends on firmware and radio target. The widget is colour-only; the monochrome images are supplied as artwork. Not every model has been physically tested. This changes the widget home view, not the global radio theme.
